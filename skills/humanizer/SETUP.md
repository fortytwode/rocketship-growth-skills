# Use Humanizer

Ask your assistant to read `SKILL.md`, then supply the text you want edited and any context needed to preserve its meaning. The linked examples are fictional illustrations of editorial decisions.

You can also copy this folder into your agent's supported skills directory. Installation interfaces vary; editor-specific installation flows have not been certified here.

This package needs no RocketShip account, scripts, connected systems or separate API key. Use the assistant you already have. It returns proposed text; it does not send, publish or change your documents by itself.
