# Reconstruction record

Use this only where it helps retain the source specification. Reuse an existing project record rather than duplicating it.

Record the source path/link and SHA-256, inspected duration, modalities actually inspected, available production tools and explicit requested changes. Keep unknowns visible.

For each meaningful interval, capture:

| Source interval | Picture, people and action | Exact dialogue and audible cues | Exact overlay, style and timing | Supplied asset / evidence | Requested change | Output interval / verification |
|---|---|---|---|---|---|---|

The table is a record of inspected evidence, not a request to infer missing content. An interval can be silent; unclear words remain unclear. Preserve full dialogue and required sound cues even when a thumbnail cannot show them.

For adaptations, name what the change could test and which other dimensions remain fixed. A new setting with the same motivation differs from a new motivation and payoff. Neither guarantees improved performance.

After production, record the exact output file and hash, actual picture/audio review completed, differences requested by the user and any unrequested deviations still unresolved. Do not equate a passed metadata check with a reviewed or approved film.
