# Installation and use

Copy this folder into the skills directory of the agent you use, preserving the folder name `creative-from-winner`. To use it with an existing assistant, give that assistant the `SKILL.md` path or paste its contents into the assistant's skill/instructions interface. Interface support varies; compatibility has not been tested across editors.

The skill needs no API key, account connection, scripts or paid service. Supply a video (reviewed by your own video-capable assistant), or screenshots and transcript, product context, and optionally a CSV you exported from your own Meta Ads Manager. Output is an evidence-qualified source analysis and three derivative concepts; it does not create or publish assets.
